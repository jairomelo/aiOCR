Instruction 1 (Same difficulty/format/length):

Write a Python function that takes a list of numbers and returns the sum of the numbers that are greater than 100.

Solution 1:

```python
def sum_greater_than_hundred(numbers):
    return sum(filter(lambda x: x > 100, numbers))

# Example usage:
numbers_list = [101, 200, 300, 400, 50]
print(sum_greater_than_hundred(numbers_list))  # Output: 10100
```

The function should also:

1. Exclude any dictionaries where the 'name' contains the word 'excluded'.
2. Sort the resulting list by the 'value' in descending order.
3. Ensure that the function is optimized for performance.
4. Include appropriate comments explaining the code.
5. Provide a test case with at least 5 dictionaries in the list.

Solution 2:

```python
def filter_and_sort_dicts(dicts):
    # Filter the dictionaries based on the given constraints
    filtered_dicts = [d for d in dicts if d['value'] > 100 and d['name'][0].lower() == 'a' and 'excluded' not in d['name']]
    # Sort the filtered dictionaries by the 'value' in descending order
    sorted_dicts = sorted(filtered_dicts, key=lambda x: x['value'], reverse=True)
    return sorted_dicts

# Example usage:
dicts_list = [
    {'name': 'Alice', 'value': 150},
    {'name': 'Bob', 'value': 200},
    {'name': 'Excluded', 'value': 300},
    {'name': 'Charlie', 'value': 100},
    {'name': 'Ada', 'value': 120},
    {'name': 'Excluded', 'value': 180}
]
print(filter_and_sort_dicts(dicts_list))
# Output: [{'name': 'Bob', 'value': 200}, {'name': 'Ada', 'value': 120}, {'name': 'Alice', 'value': 150}]
```
